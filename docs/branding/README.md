# Digital Dukan identity

The mark combines a shop awning (a small business), a rising roof/arrow (growth online), and a lime square (a digital window/pixel). Emerald keeps the identity calm and familiar; lime adds a distinctive accent.

- `public/brand-mark.svg`: compact original vector used by the platform header, dashboard, footer and platform favicon. Self-contained SVG, no fonts or remote requests.
- `public/brand-lockup.svg`: standalone horizontal wordmark for reuse.
- `logo-concept.png`: the one-time generated visual concept. This reference is not loaded by the website.
- `logo-preview.png`: rendered wordmark review image.

Merchant logos and store names remain independent. A merchant-specified favicon overrides the platform favicon. No generation API is called by the running application.
